# Manual de uso da TechBairro

## A tela principal

A TechBairro é um sistema utilizado para cadastrar e gerenciar os dados dos clientes da associação.

Na tela principal, o usuário encontra os campos Nome, Telefone, E-mail e Endereço para preencher os dados dos clientes. Também existem botões para realizar operações de cadastro e gerenciamento dos registros, além de mensagens que informam o resultado das ações.

## Cadastrar um cliente

1. Abra o programa TechBairro.
2. Preencha o campo Nome com o nome completo do cliente.
3. Digite o telefone do cliente no campo Telefone.
4. Informe o e-mail no campo E-mail.
5. Preencha o endereço no campo Endereço.
6. Confira se todas as informações estão corretas.
7. Clique no botão de salvar cadastro.
8. Verifique a mensagem apresentada pelo sistema para confirmar se o cadastro foi realizado.

## Consultar os clientes cadastrados

1. Abra o programa TechBairro.
2. Localize a lista de clientes cadastrados.
3. Procure o cliente que deseja consultar.
4. Selecione o registro desejado.
5. Confira as informações apresentadas na tela.

## Alterar os dados de um cliente

1. Localize o cliente que deseja alterar.
2. Selecione o registro na lista de clientes.
3. Clique no botão de editar.
4. Altere as informações necessárias nos campos.
5. Confira os dados preenchidos.
6. Salve as alterações.
7. Verifique a mensagem apresentada pelo sistema para confirmar se a atualização foi realizada.

## Excluir um cliente

1. Localize o cliente que deseja excluir.
2. Selecione o registro correto.
3. Clique no botão de excluir.
4. Confira se o sistema apresenta uma confirmação.
5. Confirme a exclusão somente se tiver certeza de que selecionou o cliente correto.
6. Verifique se o registro foi removido da lista.

## Regras de preenchimento

| Campo | Obrigatório? | Regra |
|---|---|---|
| Nome | Sim | Não deixe o campo vazio e informe o nome do cliente. |
| Telefone | Sim | Informe apenas números, sem letras ou símbolos. |
| E-mail | Sim | Informe um endereço de e-mail válido, contendo `@` e um ponto depois do `@`. |
| Endereço | Sim | Preencha com o endereço do cliente. |

## Mensagens do sistema

| Mensagem | O que significa | O que fazer |
|---|---|---|
| Cadastro realizado com sucesso. | O cliente foi cadastrado. | Confira se os dados estão corretos. |
| Preencha todos os campos. | Existe algum campo obrigatório vazio. | Preencha todos os campos e tente novamente. |
| Telefone inválido. | O telefone contém caracteres não permitidos. | Digite somente números. |
| E-mail inválido. | O e-mail não atende às regras de validação. | Confira o endereço e verifique se contém `@` e um ponto depois dele. |
| Cliente atualizado com sucesso. | As alterações foram salvas. | Confira os dados atualizados. |
| Deseja realmente excluir este cliente? | O sistema está pedindo confirmação da exclusão. | Confirme somente se deseja excluir o registro selecionado. |

**Atenção:** essas mensagens são exemplos para preencher a tabela. Abra o programa e substitua cada texto pelo que realmente aparece na sua TechBairro. Se o sistema não apresentar alguma dessas mensagens, não a descreva como se fosse uma mensagem existente.

## Dúvidas frequentes

**O que fazer se eu esquecer de preencher um campo?**

Preencha todos os campos obrigatórios antes de tentar salvar o cadastro novamente.

**O que fazer se o telefone for recusado?**

Confira se você digitou somente números, sem letras ou símbolos.

**Posso corrigir os dados de um cliente depois de cadastrá-lo?**

Sim. Selecione o cliente, utilize a opção de edição, corrija as informações e salve as alterações.

**Como evitar excluir o cliente errado?**

Confira os dados do cliente selecionado antes de confirmar a exclusão.

**O que fazer se o programa não abrir?**

Confira se o Python está instalado e se você está executando o programa corretamente. Se o problema continuar, peça ajuda ao responsável pela instalação.
