Perguntas por escrito

Pergunta 1: por que o arquivo "techbairro.db" não está no GitHub?

O arquivo "techbairro.db" não está no GitHub porque armazena os dados dos clientes, que podem conter informações pessoais. Para proteger a privacidade e cumprir a LGPD, o banco de dados é mantido fora do repositório.

Pergunta 2: qual caso de teste pegou um defeito de verdade? Qual era o defeito?

Um defeito identificado durante o desenvolvimento foi o cadastro de clientes com os campos trocados, fazendo com que o endereço aparecesse no campo de e-mail e o endereço ficasse vazio. A correção ajudou a garantir que cada informação fosse salva no campo correto.

Pergunta 3: se o voluntário da associação tiver só o link do repositório, como ele instala e executa a TechBairro?

O voluntário deve instalar o Python e o Git, abrir o terminal e executar "git clone https://github.com/baracho061/techbairro.git". Depois, deve entrar na pasta com "cd techbairro", verificar se o Tkinter está disponível e executar "python techbairro.py". Também pode baixar o projeto pelo botão Code → Download ZIP, extrair os arquivos e executar o programa pelo terminal.
